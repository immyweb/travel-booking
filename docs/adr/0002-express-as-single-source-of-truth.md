# Express as single source of truth; Next.js and Express always colocated

Next.js SSR pages fetch listing/search/booking data from the Express API over an internal/private connection rather than reading the database directly through the shared `Core` package, even though direct access was available and would avoid a network hop. This keeps Express as the single source of truth for all data access — useful for future non-web consumers (mobile apps, third-party integrations) — at the cost of an internal HTTP call on every SSR request. To protect the "excellent performance" requirement, Next.js and Express must always be deployed together on the same internal network (currently: both on Railway, in the same project/private network), never split across platforms where that call would cross the public internet.
